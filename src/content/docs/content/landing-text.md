Текст лендинга ведёт посетителя к одному действию.

## Порядок работы

1. Узнайте у покупателя: кто клиент, какую проблему решаем, чем отличаются.
2. Заголовок: результат для клиента, а не название компании.
3. Блоки: проблема, решение, преимущества, этапы, отзывы, вопросы, призыв.
4. Короткие абзацы, списки, конкретные цифры.
5. Каждый блок заканчивайте понятным следующим шагом.

## Типичные ошибки

- Много слов о себе, мало о пользе клиенту.
- Нет одного чёткого призыва.
- Выдуманные отзывы и цифры - делать нельзя.

## Чек-лист

- [ ] Один призыв
- [ ] Факты подтверждены
- [ ] Текст проверен покупателем
