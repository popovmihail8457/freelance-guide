`СТАТУС.md` - журнал работы по заказу, `Changelog\CHANGELOG.md` - список изменений.

## Порядок работы

1. После каждого рабочего дня запишите: что сделано, что дальше, какие решения приняты.
2. Все изменения для покупателя записывайте в Changelog.
3. Исходники покупателя не меняйте - работайте с копиями.
4. Готовое складывайте в `Результат\`.
5. Пароли, токены и доступы в файлы проекта не записывайте.

## Типичные ошибки

- Нет записи о решениях - через неделю не вспомнить, почему так.
- Секреты в журнале.
