Сдача - передача результата и проверка по критериям приёмки.

## Порядок работы

1. Пройдите чек-лист приёмки сами.
2. Подготовьте результат и инструкцию (как запускать, где что лежит).
3. Отправьте покупателю результат и список выполненных критериев.
4. Примите правки в рамках согласованного числа кругов.
5. Для доработок вне брифа предложите допуслугу.

## Типичные ошибки

- Сдача без инструкции.
- Бесплатные доработки вне брифа.

## Чек-лист

- [ ] Критерии пройдены
- [ ] Инструкция приложена
- [ ] Правки ограничены

Отправку сообщений покупателю делаете вы или только после вашего «да».
