SEO - подготовка сайта к поиску. Для лендинга главное: понятные тексты и технические основы.

## Что настроить

- Уникальный `title` (до ~60 символов) и `description` (до ~160).
- Один `h1`, логичная иерархия `h2`-`h3`.
- Атрибут `alt` у картинок.
- Файлы `robots.txt` и `sitemap.xml`.
- Разметка Open Graph для превью в мессенджерах.
- Скорость: сжатые картинки, минимум скриптов.

## Порядок работы

1. Подберите запросы, по которым ищут услугу.
2. Включите ключевые слова в заголовки и текст естественно.
3. Проверьте Lighthouse (SEO, Performance).
4. Подайте сайт в Яндекс Вебмастер и Google Search Console.

## Типичные ошибки

- Одинаковые `title` на всех страницах.
- Текст для роботов, а не для людей.

## Чек-лист

- [ ] title, description, h1
- [ ] robots.txt и sitemap
- [ ] Lighthouse SEO не ниже 90

Для проверки сайта есть агент `seo-specialist`.
