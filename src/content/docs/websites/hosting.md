Чтобы сайт увидели все, его надо разместить на хостинге и привязать домен.

## Варианты для статических сайтов

| Сервис | Особенности |
|---|---|
| Cloudflare Pages | Бесплатно, быстро, свой домен |
| GitHub Pages | Бесплатно, из репозитория |
| Netlify, Vercel | Бесплатные тарифы, простая публикация |
| Обычный хостинг | Платно, загрузка файлов по FTP |

## Порядок работы

1. Соберите сайт: `npm run build` (готовые файлы в папке `dist`).
2. Загрузите на выбранный сервис.
3. Купите домен у регистратора (оплачивает покупатель).
4. Укажите DNS-записи, дождитесь HTTPS-сертификата.
5. Передайте покупателю доступы к хостингу и домену на его аккаунте.

## Типичные ошибки

- Домен куплен на исполнителя, а не на заказчика.
- Нет HTTPS.
- Не передан доступ к аккаунту хостинга.

## Чек-лист

- [ ] Сайт открывается по домену с HTTPS
- [ ] Домен и хостинг оформлены на покупателя
- [ ] Инструкция по обновлению передана
