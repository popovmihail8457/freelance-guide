Навык - набор инструкций под тип задачи. Подгружается по запросу.

## Полезные навыки

- `vectorlab-ux-skills:*` - цвета, шрифты, отступы, адаптив, UX-аудит.
- `browser-qa` - проверка сайта в браузере.
- `figma:figma-design-to-code` - макет Figma в код.
- `codebase-onboarding` - разбор чужого кода.
- `freelance-replies` - тексты откликов и описаний.
- `interactive-docs` - интерактивные инструкции для покупателя.

## Как использовать

Назовите навык в запросе или вызовите командой `/имя-навыка`.
