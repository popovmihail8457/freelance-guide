Агенты - специалисты, которых запускает Claude Code под конкретную задачу. Они работают отдельно и возвращают результат.

## Основные агенты

| Агент | Для чего |
|---|---|
| `planner` | План работ |
| `architect` | Архитектура |
| `tdd-guide` | Тесты вперёд |
| `code-reviewer` | Ревью кода после правок |
| `security-reviewer` | Проверка безопасности |
| `a11y-architect` | Доступность |
| `seo-specialist` | SEO-проверка |
| `docs-lookup` | Актуальная документация библиотек |

## Как использовать

Напишите задачу и название агента: «используй code-reviewer для папки bot». Claude запустит агента и вернёт вывод.
