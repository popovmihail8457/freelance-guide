Коннекторы подключают Claude к внешним сервисам.

| Что | Для чего | Статус |
|---|---|---|
| Playwright | Проверка сайтов, скриншоты | Подключён |
| Figma | Верстка по макету | Нужна авторизация |
| GitHub | Хранение кода, сдача | Не подключён, подключается через настройки |

## Правила

- Права и авторизацию выдаёте вы сами.
- Не подключайте плагины с доступом к личным аккаунтам без необходимости.
- Токены и пароли в файлах проекта не храните.
