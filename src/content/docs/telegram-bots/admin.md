Админ-панель - способ для владельца управлять ботом без правки кода: рассылки, баллы, пользователи, статистика.

## Типичные функции

- Просмотр и поиск пользователей.
- Ручное начисление и списание баллов.
- Рассылка сообщений.
- Статистика: новые пользователи, активность.
- Блокировка пользователя.

## Порядок работы

1. Определите админов по `telegram_id` из `.env`.
2. Все админ-команды проверяют, что пользователь - админ.
3. Опасные действия (рассылка, списание) просите подтвердить.
4. Рассылку отправляйте с паузой, чтобы не упереться в лимиты Telegram.

## Типичные ошибки

- Проверка админа только скрытием кнопки, а не в обработчике.
- Рассылка без подтверждения.
- Нет журнала действий администратора.
