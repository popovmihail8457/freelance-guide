Для ботов на Python чаще всего берут **aiogram** (асинхронный, современный) или **python-telegram-bot**. Выбор: aiogram 3 для новых проектов.

## Структура проекта

```
bot/
  main.py          точка входа
  config.py        чтение .env
  handlers/        обработчики команд и кнопок
  keyboards/       клавиатуры
  db/              работа с базой
  services/        бизнес-логика (баллы, уровни)
.env               токен (не в git)
requirements.txt
```

## Порядок работы

1. Создайте виртуальное окружение: `python -m venv .venv`.
2. Установите библиотеку: `pip install aiogram`.
3. Напишите `/start` и убедитесь, что бот отвечает.
4. Разделите логику по папкам, а не пишите всё в одном файле.
5. Зафиксируйте зависимости в `requirements.txt`.

## Типичные ошибки

- Один файл на 1000 строк.
- Блокирующие запросы внутри async-обработчиков.
- Нет обработки ошибок: бот падает на неожиданном вводе.
