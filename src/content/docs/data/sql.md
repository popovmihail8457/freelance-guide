SQL - язык запросов к базам данных. Заказы: написать запросы, оптимизировать, настроить отчёт.

## Порядок работы

1. Изучите схему: таблицы, поля, связи.
2. Начните с простого `SELECT`, затем добавляйте условия и `JOIN`.
3. Для агрегатов используйте `GROUP BY`.
4. Проверьте план запроса, добавьте индексы по часто используемым полям.
5. Опасные операции (`UPDATE`, `DELETE`) сначала выполняйте как `SELECT` с тем же условием.

```sql
SELECT customer_id, SUM(amount) AS total
FROM orders
WHERE created_at >= DATE '2026-01-01'
GROUP BY customer_id
ORDER BY total DESC;
```

## Типичные ошибки

- `DELETE` без `WHERE`.
- Запрос без ограничения по числу строк на большой таблице.
