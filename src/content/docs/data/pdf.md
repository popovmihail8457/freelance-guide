Задача: достать таблицы или текст из PDF и получить Excel.

## Порядок работы

1. Выясните тип PDF: текстовый (можно выделить текст) или скан (нужно распознавание).
2. Для текстового используйте навык `pdf-to-excel` или библиотеки для таблиц.
3. Для скана нужен OCR, точность ниже, поэтому проверяйте вручную.
4. Сверьте итоговые суммы и количество строк с исходником.

## Типичные ошибки

- Не сверены суммы.
- Таблицы, разорванные между страницами, склеены неправильно.

## Чек-лист

- [ ] Тип PDF определён
- [ ] Суммы сходятся
- [ ] Сложные места проверены вручную
