Типичные задачи: очистить таблицу, объединить файлы, посчитать, сделать отчёт.

## Порядок работы

1. Сохраните исходный файл без изменений, работайте с копией.
2. Определите структуру: колонки, типы, ключ строки.
3. Очистка: пробелы, дубликаты, разный формат дат и чисел.
4. Для больших объёмов используйте Python (`pandas`).
5. Проверьте итоги выборочно.

## Типичные ошибки

- Работа поверх исходного файла.
- Числа и даты в виде текста.
- Формулы ломаются при сортировке.
