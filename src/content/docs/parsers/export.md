Результат парсера удобнее всего отдавать в **CSV** (универсально) или **Excel** (удобно покупателю).

## Порядок работы

1. Определите колонки вместе с покупателем.
2. Для CSV используйте кодировку `utf-8-sig`, чтобы Excel правильно показал русский.
3. Для Excel: `pandas` + `openpyxl` (`df.to_excel("result.xlsx", index=False)`).
4. Названия колонок - понятные, на языке покупателя.
5. Добавьте столбец с датой сбора и ссылкой на источник.

## Типичные ошибки

- Кракозябры в CSV из-за кодировки.
- Числа сохранены как текст.
- Дубликаты строк.

## Чек-лист

- [ ] Колонки согласованы
- [ ] Дубликаты удалены
- [ ] Файл открывается в Excel без ошибок
