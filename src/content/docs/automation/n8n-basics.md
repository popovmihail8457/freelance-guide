**n8n** - сервис, где автоматизации собирают из блоков (узлов): триггер запускает цепочку действий.

## Основные понятия

- **Триггер**: что запускает (расписание, вебхук, новое письмо, сообщение).
- **Узел**: шаг (запрос, условие, запись в таблицу, отправка в Telegram).
- **Credentials**: сохранённые доступы к сервисам. Не показывайте их в скриншотах.

## Порядок работы

1. Опишите процесс словами: «если ..., то ...».
2. Определите вход и выход данных.
3. Соберите цепочку, тестируя каждый узел на тестовых данных.
4. Добавьте обработку ошибок и уведомление.
5. Включите workflow только после проверки.

## Типичные ошибки

- Тестирование сразу на боевых данных.
- Доступы вписаны в узлы вместо credentials.
