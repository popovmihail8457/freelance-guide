Автоматизация ломается: сервис недоступен, данные пришли странные, лимит исчерпан. Подготовьтесь заранее.

## Что предусмотреть

- Повтор запроса при временной ошибке (с растущей паузой).
- Проверка данных на входе.
- Уведомление владельца при сбое.
- Защита от дублей при повторном запуске.
- Журнал запусков.

## Порядок работы

1. Для каждого шага подумайте: «что если он не сработает?».
2. Настройте обработчик ошибок и уведомление.
3. Проверьте на заведомо плохих данных.

## Чек-лист

- [ ] Повторы и уведомления
- [ ] Нет дублей
- [ ] Журнал есть
