**Вебхук** - адрес, на который другой сервис присылает данные при событии. **API** - способ запросить или отправить данные сервису.

## Порядок работы

1. Прочитайте документацию API: адрес, метод, авторизация, лимиты.
2. Проверьте запрос отдельно (например, в Postman или curl).
3. Для вебхука: настройте адрес приёма и проверяйте подпись или секрет.
4. Сохраните примеры запросов и ответов для документации.

## Типичные ошибки

- Нет проверки подлинности вебхука.
- Игнорируются лимиты запросов.
- Ключ API в открытом виде.

## Чек-лист

- [ ] Авторизация настроена
- [ ] Лимиты учтены
- [ ] Ключи хранятся безопасно
