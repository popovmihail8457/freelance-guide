Доступность - сайтом могут пользоваться все: люди с плохим зрением, без мыши, на медленных устройствах.

## Что проверить

- Контраст текста не ниже 4.5:1.
- Управление с клавиатуры, видимый фокус.
- `alt` у значимых картинок.
- Метки у полей форм.
- Уважение `prefers-reduced-motion` для анимаций.
- Правильные заголовки и ориентиры (`nav`, `main`).

## Порядок работы

1. Пройдите страницу клавишей Tab.
2. Запустите Lighthouse (Accessibility).
3. Исправьте найденные проблемы.

## Типичные ошибки

- Серый текст на светлом фоне.
- Убран outline у кнопок без замены.

## Чек-лист

- [ ] Контраст и фокус
- [ ] alt и label
- [ ] Lighthouse Accessibility не ниже 90

Для проверки есть агент `a11y-architect`.
