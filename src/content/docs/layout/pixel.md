Сверка с макетом - проверка, что результат совпадает с дизайном.

## Порядок работы

1. Откройте макет и страницу рядом на одной ширине.
2. Сравните: отступы, размеры шрифта, межстрочный интервал, выравнивание.
3. Проверьте 3 ширины: 375, 768, 1280 px.
4. Сделайте скриншоты (Playwright) и сравните с макетом.
5. Проверьте состояния: наведение, фокус, активность, ошибки.

## Типичные ошибки

- Сверять «на глаз» только на одной ширине.
- Не проверять состояния.

## Чек-лист

- [ ] Три ширины проверены
- [ ] Состояния проверены
- [ ] Покупатель утвердил результат скриншотами
