Плагины расширяют сайт. Каждый плагин - риск для скорости и безопасности.

## Порядок работы

1. Берите плагины из официального каталога с актуальными обновлениями и хорошими отзывами.
2. Не ставьте взломанные («nulled») версии.
3. Ограничьте число плагинов: каждый лишний замедляет сайт.
4. После установки проверьте скорость и работу форм.

## Типичные ошибки

- Нулленные плагины с вирусами.
- Много плагинов с одинаковыми функциями.

## Чек-лист

- [ ] Плагины из надёжных источников
- [ ] Лишние удалены
- [ ] Обновления включены
